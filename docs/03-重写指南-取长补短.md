# 重写指南：取长补短（交给 AI 的实现指令）

> 基于《01-Everything-功能实现文档》《02-Listary-功能实现文档》两份规格。
> 本文直接回答：**重写一个程序，应该实现哪些功能、每个功能抄谁、什么顺序做。**

---

## 0. 产品定位建议

重写目标 = **"Everything 的索引内核与速度" + "Listary 的搜索体验与场景集成"**：

- 底层：USN 驱动 + 内存索引 + 差分压缩 + 原子落盘（学 Everything）
- 中层：模糊匹配 + 拼音 + 评分排序 + 上下文加权（学 Listary）
- 上层：一个搜索框（窗口/托盘/热键）+ 文本 IPC + HTTP API（学 Everything 的开放）+ 对话框钩子（学 Listary 的场景，后期）

名字延续 FlashFind（已有实现在 `FlashFind\`，172 万条实测：建索引 69s / 载入 0.26s / 子串 26–182ms）。

## 1. 功能清单与取源

### 1.1 必须实现（P0）——两款共有或某款独占且核心

| # | 功能 | 抄谁 | 实现要点 |
|---|---|---|---|
| 1 | USN Journal 索引（全量+增量） | **Everything** | FSCTL 三件套；V3 记录 128 位 FRN 的坑；SeManageVolumePrivilege 提权；ERROR_HANDLE_EOF 是正常结束 |
| 2 | MFT 直读全量索引（快速路径） | **Listary** | 打开 `\\.\C:` 读 `$MFT::$DATA`；解析记录 0 拿 data run；逐记录解析 $STANDARD_INFORMATION/$FILE_NAME/$DATA；FRN 挂 folder tree。USN 枚举作为备选路径 |
| 3 | 内存索引 + 落盘 | **Everything** | 分块数组（493/块）+ 属性列按 flags 位挂载；名字前向差分或整名 blob+压缩；tmp+原子替换 |
| 4 | 布尔查询语法 | **Everything** | 帧栈机；`!`/`NOT`、`(`/`)`、AND/OR；修饰符表（case/wildcards/regex/wholeword/path/file/folder/ext/size/dm/…） |
| 5 | 属性过滤 | **Everything** | `size:`（单位 b/kb/mb/gb/tb/pb，比较符 > >= < <= =）、`dm:/dc:/da:`、`parent:/infolder:/depth:`、`attrib:`、`startwith:/endwith:`、`runcount:`、`dupe:` |
| 6 | **模糊匹配** | **Listary** | 字符序匹配（"vsc"→"Visual Studio Code"）+ 位置位图剪枝 |
| 7 | **中文拼音** | **Listary** | 全拼 + 首字母 +（可选）模糊拼音；用开源拼音库数据，不必逆 cnmatch.bin |
| 8 | **评分排序** | **Listary** | score = 命中位置权重 + 连续度 + 全词/大小写加分 + PriorFolders 上下文 + 用户优先级规则（Folder/FileName/Extension/Attribute） |
| 9 | 调用入口 | **Everything** | 文本 IPC（WM_COPYDATA + `FF <CMD>` 或兼容 `EVERYTHING <CMD>`）+ HTTP JSON API；分页 offset/count |
| 10 | UI | 两者 | 搜索框 + 结果 ListView + 托盘 + 全局热键；双击 Ctrl 唤出（Listary 形态） |

### 1.2 第二阶段（P1）——体验加分

| # | 功能 | 抄谁 | 要点 |
|---|---|---|---|
| 11 | 快照/双缓冲（写不阻塞读） | **Listary** | RocksDB snapshot 思想；纯内存实现 = 双缓冲数组 + 原子切换 |
| 12 | 两段式搜索 | **Listary** | 先返回总数+摘要（首屏 <50ms），再按 offset/limit 取详情 |
| 13 | 对话框钩子 | **Listary** | HookHost 注入 + 挂 dialogbox；在打开/保存框里唤出搜索跳转 |
| 14 | 多提供器启动器 | **Listary** | 一个输入框路由到：文件搜索 / 计算器 / 命令 / 网页搜索 / 当前目录 |
| 15 | 优先级规则（用户可配） | **Listary** | FolderPriority / FileNameRegexPriority / FileExtensionPriority / FileAttributePriority，热更新 |

### 1.3 第三阶段（P2）——Everything 更长的地方

| # | 功能 | 抄谁 | 要点 |
|---|---|---|---|
| 16 | **内容全文搜索** | **Everything** | `content:` 族（utf8/utf16le/be/ansi/wchar）；默认 40 种文本扩展表；纯文本抽词 + 倒排或逐文件扫 |
| 17 | 硬链接去重 | **Listary** | 同文件多路径合一存（一个 id + 多链接槽） |
| 18 | filelist CSV 导入 | **Everything** | 9 列格式（Name/Size/Date Modified/Created/Accessed/Attributes/Run Count/Date Run/Recently Changed） |
| 19 | 历史/书签/过滤器 | 两者 | PathHistory/SearchHistory JSON（Listary 形态，CRDT 变更集）或 CSV（Everything 形态） |
| 20 | 服务形态 + 提权 | **Listary** | UI 低权限、索引服务提权，gRPC/管道通信 |

## 2. 架构建议（重写蓝图）

```
┌────────────────────────────────────────────┐
│ UI 层（一个搜索框）                          │
│  窗口/托盘/热键/双击Ctrl · 结果 ListView · 预览 │
└──────────────┬─────────────────────────────┘
               │ 文本 IPC / HTTP JSON / （后期）对话框钩子
┌──────────────▼─────────────────────────────┐
│ 查询层                                     │
│  解析器(帧栈机) → term 链表 + 条件链表        │
│  求值：子串/通配/正则/模糊/拼音 → 候选集       │
│  评分：位置+连续+上下文+规则 → 排序 → 分页     │
└──────────────┬─────────────────────────────┘
┌──────────────▼─────────────────────────────┐
│ 索引层（引擎，可独立进程/服务）               │
│  MFT 直读(全量) + USN(增量) + 目录遍历(补充)  │
│  内存: folder/file 分块数组 + 属性列          │
│  落盘: 差分名字 + 压缩 + tmp 原子替换         │
│  一致性: 双缓冲/快照，写不阻塞读              │
└────────────────────────────────────────────┘
```

技术栈自由；关键是**索引内核照 Everything、匹配层照 Listary**。

## 3. 实施顺序（里程碑）

```
M1 索引能建：USN/MFT 全量 → 内存数组 → 可搜索（子串）      [核心]
M2 索引能存：差分/压缩落盘 → 载入 → 增量更新（USN 续读）     [持久化]
M3 查询能用：帧栈机解析 → 修饰符+属性操作符 → 排序分页       [查询]
M4 体验上线：模糊 + 拼音 + 评分 + 上下文加权                  [Listary 精华]
M5 入口开放：文本 IPC + HTTP JSON API                        [集成]
M6 场景集成：托盘/热键/双击Ctrl →（后期）对话框钩子           [产品化]
M7 高级项：内容搜索 / 硬链接去重 / filelist 导入 / 服务形态    [完整]
```

每步都有明确验收标准（M1 验收：100 万条建索引 <90s、子串查询 <200ms——参考已实现的 FlashFind 实测）。

---

## 4. 明确不要抄的东西

- Everything 的 ETP/FTP 服务端（协议老旧，HTTP/JSON 已覆盖）
- Listary 的 Sentry/RudderAnalytics 遥测、WebView2 内嵌网页（产品决策，非技术必需）
- Listary 的 gRPC（除非要多机同步；单机用共享内存/管道更轻）
- 两款的多语言框架（先做中文+英文）

---

## 5. 一页总结

```
索引：  USN 增量（Everything）+ MFT 直读全量（Listary）
存储：  前向差分/压缩 + 原子落盘（Everything）+ 快照读写分离（Listary）
查询：  布尔语法 + 属性操作符（Everything）+ 模糊/拼音/评分（Listary）
入口：  文本 IPC + HTTP（Everything）+ 对话框钩子/双击Ctrl（Listary，后期）
```
