⚡

毫秒级搜索

200 万条索引上，子串查询 2.5 ms、AND 组合 3.2 ms。输入即出结果，没有加载转圈。

🔄

USN 增量

首次全扫建索引，此后只读 NTFS USN 日志的变更。关机期间的改动，下次启动自动补齐。

💾

重启秒开

索引落盘复用，不再每次重新扫描。开启索引复用后，二次启动从 22 秒全扫降到亚秒级载入。

🀄

拼音与模糊

记不清全名？支持拼音匹配与子序列模糊搜索，模糊输入也能命中目标文件。

⌨️

全局热键唤出

无边框窗口常驻托盘，Ctrl+Alt+Space 随时唤出，失焦自动隐藏，不打断工作流。

🔍

工作原理

一次建索引，此后只追增量

Rust 工作区负责索引与匹配，Tauri + React 承载界面。

01

MFT 全量扫描

直接读取 NTFS 主文件表，秒级建立全卷索引。

02

USN 增量追踪

后台轮询 USN 日志，把新增/删除/改名合并进内存索引。

03

落盘与复用

索引 + 续读起点一起落盘，重启载入后从断点继续。

04

即时匹配排序

子串 / 拼音 / 模糊并行匹配，评分排序后虚拟化呈现。

快速开始

从源码构建正式版

需要 Rust stable 与 Node.js 18+。一条命令构建前端与内嵌资源的 exe。

# 克隆并构建
git clone https://github.com/CC123xing-U/sift.git
cd sift/app
npm install
npm run build:release # 产物: src-tauri/target/release/sift-app.exe
# 双击运行，首次启动自动建索引；Ctrl+Alt+Space 唤出

完整说明与查询语法见仓库 README.md。普通权限可选用 Windows 服务模式（命名管道），管理员权限自动回退进程内引擎。
